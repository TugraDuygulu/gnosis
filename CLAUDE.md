## Shared project context
Read [AGENTS.md](AGENTS.md) first and follow its links to the current project
snapshot, relevant issue and task-specific documentation. Read the linked files;
this pointer does not assume the tool loads them automatically. Keep shared rules
there rather than duplicating them in a tool-specific file.

## Design System
Read DESIGN.md before visual or UI work: it defines the fonts, colors, spacing, and
aesthetic direction. Ask the user before departing from it. When reviewing or QA-ing
UI, flag code that doesn't match DESIGN.md.
