How the file works

Blank keeps the current grade, even when it isn’t graded yet. To clear a grade, use the grade book.
00 records a real zero.
42.5A number sets the score. Use a dot for decimals, at most 2 places, up to the assessment’s maximum.

  • Each student and assessment appears once.
